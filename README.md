# 围棋复盘系统

儿童围棋 AI 复盘助手，帮助 9-12 岁小棋手轻松分析对局。

## 项目简介

这是一款专注于儿童围棋学习的在线复盘工具，通过 AI 辅助分析帮助孩子理解棋局，提升棋力。

## 功能特性

- ✅ SGF 棋谱上传与解析
- ✅ 交互式棋盘浏览（支持 9/13/19 路）
- ✅ 胜率曲线可视化
- ✅ 试下功能（探索不同着法）
- ✅ AI 复盘分析（问题手识别、文字评价）
- ✅ 本地存储复盘记录
- ✅ 响应式设计，支持移动端

## 技术栈

- **前端**：纯 HTML + CSS + JavaScript（单文件架构）
- **渲染**：Canvas 2D + SVG
- **AI 引擎**：KataGo（规划中，当前版本使用规则模拟）
- **存储**：localStorage
