## 修复记录（2026-03-20 22:45）

### Bug 修复：棋盘点击误跳转问题

**问题描述**：
- 用户点击棋盘空白处时，如果该位置历史上下过棋，进度条会自动跳转
- 这导致严重的误操作问题，用户只是想浏览棋盘却不小心跳到了其他位置

**修复方案**：
- 修改 `bindBoardEvents()` 中的 click 事件处理逻辑
- 添加检查：只有当前棋盘局面**已有棋子**的位置才允许点击跳转
- 点击空白处不再触发跳转，避免误操作

**修复代码位置**：`go-review-v1.0.0.html` 第1740行附近

```javascript
// 检查当前局面该位置是否有棋子（有棋子才允许跳转，避免误触）
const hasStone = App.renderer.stones && App.renderer.stones[y] && App.renderer.stones[y][x] !== 0;
if (!hasStone) return; // 点击空白处不跳转，避免误操作
```
